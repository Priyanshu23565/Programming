📘 Chapter 11 – 2D Transforms in CSS

🔀 Translate – Move Karna

transform: translate(x, y) element ko X (horizontal) aur Y (vertical) direction me move karta hai.
🧠 Positive → right/bottom, Negative → left/top
<div style="transform: translate(50px, 20px);">
  👉 Yeh box 50px right aur 20px niche gaya
</div>
👉 Yeh box 50px right aur 20px niche gaya

🔄 Rotate – Ghumao

transform: rotate(deg) element ko angle ke hisaab se ghumata hai.
🧠 Positive = clockwise, Negative = anti-clockwise
<div style="transform: rotate(45deg);">
  🔄 Yeh box 45° ghoom gaya
</div>
🔄 Yeh box 45° ghoom gaya

🔍 Scale – Zoom In/Out

transform: scale(x) size ko zoom in ya zoom out karta hai.
🧠 scale(2) = 2x bada, scale(0.5) = aadha
<div style="transform: scale(1.5);">
  🔍 1.5x Bada ho gaya
</div>
🔍 1.5x Bada ho gaya

💫 Skew – Tilt Karna

transform: skew(x, y) element ko X aur Y axis par tilt karta hai.
🧠 Jitna angle doge, utna jhukega
<div style="transform: skew(20deg, 10deg);">
  💫 Yeh box tilt ho gaya X aur Y dono axis me
</div>
💫 Yeh box tilt ho gaya X aur Y dono axis me

🔬 Matrix – All in One

transform: matrix(a, b, c, d, e, f) — sab transforms ek hi line me apply karta hai.
⚙️ a=scaleX, b=skewY, c=skewX, d=scaleY, e=translateX, f=translateY
<div style="transform: matrix(1, 0.3, 0.2, 1, 40, 20);">
  🔧 Matrix transform laga hai
</div>
🔧 Matrix transform laga hai

🖼️ Hover Effect – Ghoomo + Zoom

Hover karne par element ghoomega bhi aur bada bhi hoga.
💡 Use transition: for smooth animation
<div class="hover-box">🌀</div>

.hover-box {
  width: 100px;
  height: 100px;
  background: tomato;
  transition: 0.3s;
}

.hover-box:hover {
  transform: rotate(15deg) scale(1.2);
}
